# Architecture decision records

Architecture decisions are numbered, dated, and treated as durable contracts. A decision's status describes the decision, not proof that every implementation detail already conforms.

| ADR | Status | Decision |
| --- | --- | --- |
| [0001](./0001-oss-core-cloud-boundary.md) | Accepted | Keep a complete Apache-2.0 core and a separate private managed-service layer |
| [0002](./0002-capability-truth-contract.md) | Accepted | Publish capability status from one canonical metadata module |
| [0003](./0003-evidence-coverage-delivery-gate.md) | Accepted | Replace synthetic quality scores with deterministic claim provenance and delivery gating |

Superseded records should remain in this directory with their status changed and a link to the replacement decision.
